# Amigazos Draft Kit

Guía de draft para la liga **Amigazos** (14 equipos, PPR). Una sola página, sin instalar nada.

- **Board general:** todos los jugadores ordenados por su valor para esta liga.
- **Tu pick ahora:** marca los picks conforme salen y te dice a quién te
  conviene tomar según tu equipo y qué posiciones se están acabando. No
  recomienda lesionados. Funciona en el navegador, sin internet ni cuenta.

Datos actualizados al 6 de septiembre de 2026. Es una guía, no una regla.
