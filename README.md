# Amigazos Draft Kit

Cheat sheet de draft para la liga **Amigazos** (14 equipos, PPR completo).
Página estática de un solo archivo (`index.html`) — sin build, sin dependencias.

- Board general ordenado por una mezcla de consenso de expertos (ECR de
  FantasyPros) y valor sobre reemplazo (VORP) para liga de 14.
- Plan por rondas e instrucciones.
- **Asistente de pick en vivo**: marca los picks conforme salen y te recomienda
  a quién tomar por necesidad × VONA. Todo corre en el navegador; se guarda en
  `localStorage`, no necesita internet ni cuenta.

Rankings: consenso de FantasyPros al 6 de septiembre de 2026. Proyecciones de
temporada de ESPN (orientativas).

Hecho por Tona Barrera · **TB · Fantasy**

## Ver / desplegar

Es HTML estático. Cualquier host sirve:

- **Local:** abre `index.html` en el navegador.
- **GitHub Pages:** Settings → Pages → Source: `main` / `/` (root).
- **Vercel:** [vercel.com/new](https://vercel.com/new) → importa este repo →
  Framework preset **Other**, sin build command, output directory `.` → Deploy.
